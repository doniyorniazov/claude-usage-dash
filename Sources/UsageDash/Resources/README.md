# Resources

Drop a `ClaudeIcon.png` here (square, ideally 36×36 or 72×72 for retina) and rebuild.

The app loads it as a template image — pure black/transparent renders as white in a dark
menu bar and black in a light one. Alpha is preserved; color channels are ignored.

If no `ClaudeIcon.png` is present, the app falls back to the hand-drawn `ClaudeMark` shape.
